parse-verdict agree packet-for-packet with the pinned katran balancer

plus quirk catalog, eBPF deliverable, memory.

## Global constraints

Same as dpdk_ptype: full gate green per commit; floors only ratchet;
goldens minted only by the factory (privileged — `dev-priv.sh`);
byte-identity on re-mints; disagreements investigated against source,
never golden-edited; latent-bug protocol.

## Config C = empty maps

All maps empty/array-default. QUIC moved to the design's boundary
(config-gated ⇒ not packet-pure — see design §6), so no vip config is
needed: the whole modeled core parse is observable with empty maps.

## Corpus matrix

**Accepts / PASS (core):** v4 TCP, v4 UDP, v6 TCP, v6 UDP, v6 with a
non-ext non-L4 nexthdr (e.g. proto 89 OSPF → PASS stage 1), IPv4
proto=4 IPIP (default build → PASS stage 1, NOT decap — boundary
proof), TCP with SYN set (flags), TCP with RST set, v4 tos/dscp
nonzero, v6 traffic-class+flow-label (tos projection).

**DROP:** v4 ihl=6 (options), v4 MF frag, v4 offset frag, v6 Fragment
nexthdr, truncated v4 header, truncated v6 header, truncated TCP (after
L3 — verify katran's XDP_DROP vs our reject: modeled or boundary),
truncated inner IP behind ICMP, ICMP inner v4 ihl=6.

**XDP_TX:** ICMPv4 echo request, ICMPv6 echo request.

**PASS via ICMP inner (F_ICMP, swapped keys):** ICMPv4 dest-unreach +
inner v4/TCP, ICMPv4 frag-needed + inner v4/UDP, ICMPv6 pkt-too-big +
inner v6/TCP, ICMPv6 dest-unreach + inner v6/UDP.

**Non-parser PASS:** ARP (stage 0), unknown EtherType (stage 0).

~30 lines. < 14B excluded (oracle unreachable). (QUIC lines dropped —
boundary.)
