# Metadata v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Declared, typed, read-write parse metadata in the IR — programs declare ≤64-bit unsigned metadata fields, states assign to them, expressions (select keys) read them, and final values are part of the parse result across interp, all four codegen backends, symex witnesses, and conformance.

**Architecture:** Additive schema change (`Parser.metadata`, `State.assigns`, `Expr.MetadataRef`), then semantics radiate outward from the reference interpreter: validator → interp → eDSL → symex (substitution store, no new `Term` leaf, no z3 change) → C/eBPF → Lua → P4/docgen → a new gallery toy example `counted_items` that exercises both the constant-write path and the accumulator-loop read path.

**Tech Stack:** Rust (prost/pbjson generated pb types, z3 via `symex` feature), Python eDSL (vendored protoc `_pb`), C99/eBPF/Lua(Wireshark)/P4-16(v1model) backends.

**Spec:** `docs/superpowers/specs/2026-07-24-metadata-v1-design.md`. Consumer: rung 4a (planned separately).

## Global Constraints

- `max_depth` is the sole termination authority; metadata never extends the budget (spec invariant 1). Assignments are total: no new reject reasons anywhere.
- Metadata fields: unsigned, `bits` 1..=64, `init` must fit; assignment truncates to width (mod 2^bits); reads zero-extend; wrapping u64 arithmetic identical to existing `Expr` eval.
- Execution order within a state: extracts → assigns (declared order; later assigns see earlier writes) → transition.
- **Zero-metadata parsers must produce byte-identical generated artifacts.** All backend emissions are conditional on `!parser.metadata.is_empty()` (or per-state `!s.assigns.is_empty()`). The existing pin tests (`committed_c_artifacts_current`, `committed_dissector_current`, `committed_p4_artifact_current`, `committed_doc_current`) enforce this for free — they must stay green through every task before Task 9.
- **v1 restriction (plan-level, documented in spec by Task 1):** `byte_len` expressions must NOT reference metadata (validator-enforced). Reason: `symex/pathid.rs:80` re-classifies oob/trunc by re-evaluating `byte_len` exprs from an env built from **final** header values (`pathid.rs:24-32`); a metadata value can change between the mid-parse evaluation and the end of the parse, so replayed classification would be unsound. Select keys are unaffected (arm decisions come from the recorded trace, never re-evaluated). Lift path: replay assigns in pathid's walk. No driver needs metadata-sized regions today.
- **v1 comparison boundaries (documented, not silent):** the eBPF harness compares only the packed verdict (`c.rs:896-925`) and the BMv2 oracle only a header bitmap (`bmv2.rs:318`) — metadata is not observed on those two channels in v1. Semantics are still covered: eBPF compiles the identical `Emit::core()` output as C (which does compare metadata), and P4's `meta` is exercised by p4test compilation.
- Full gate: `cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test && buf lint && cd py && ruff check . && pyright && pytest` (run via `./dev.sh`). Cargo tests that need z3: `cargo test --features symex`.
- Regen: gallery via `./dev.sh scripts/gen-examples.sh`; vendored Python pb via the protoc command in `py/README.md`.
- Commit style: `feat(scope): ...` / `test(scope): ...` matching `git log`; every commit ends with the repo's Co-Authored-By trailer.

```python
from __future__ import annotations

from dataclasses import dataclass

from ._expr import Operand
from ._pb import ir_pb2


@dataclass
class MetaFieldSpec(Operand):
    width_bits: int
    init: int = 0
    display_name: str = ""
    format: ir_pb2.DisplayFormat = ir_pb2.DISPLAY_FORMAT_UNSPECIFIED
    doc: str = ""
    name: str = ""  # filled by Meta.__init_subclass__

    def as_expr(self):  # -> Expr
        from ._expr import Expr

        return Expr(meta_ref=self)


def meta_bits(
    width: int,
    display: str = "",
    format: ir_pb2.DisplayFormat = ir_pb2.DISPLAY_FORMAT_UNSPECIFIED,
    *,
    init: int = 0,
    doc: str = "",
) -> MetaFieldSpec:
    if not 1 <= width <= 64:
        raise ValueError(f"metadata width {width} outside 1..=64")
    if init < 0 or (width < 64 and init >= 1 << width):
        raise ValueError(f"metadata init {init} does not fit in {width} bits")
    return MetaFieldSpec(width_bits=width, init=init, display_name=display, format=format, doc=doc)


class Meta:
    _fields: list[MetaFieldSpec] = []

    def __init_subclass__(cls, **kwargs: object) -> None:
        super().__init_subclass__(**kwargs)
        fields: list[MetaFieldSpec] = []
        for attr, value in vars(cls).items():
            if isinstance(value, MetaFieldSpec):
                value.name = attr
                fields.append(value)
        cls._fields = fields
        if not fields:
            raise ValueError(f"metadata class {cls.__name__!r} declares no fields")

    def __init__(self) -> None:
        raise TypeError("Meta classes are declarations; do not instantiate")
```

```python
max_depth (not the count field) bounds the parse: count > 5 rejects with
"max depth exceeded" — metadata never extends the budget.

from pakeles import Header, Meta, Parser, assign, bits, extract, meta_bits, parser
from pakeles.fmt import DEC, HEX


class Count(Header):
    n = bits(8, "Item Count", DEC)

    v = bits(8, "Value", HEX)


class CountMeta(Meta):
    done = meta_bits(1, "Done", DEC, doc="set on the pass-through completion state")
    remaining = meta_bits(8, "Remaining", DEC, doc="items left to read")


def counted_items() -> Parser:
    return parser(
        "counted_items",
        max_depth=8,
        metadata=CountMeta,
        start="parse_count",
        states={
            "parse_count": extract(Count)
            .assign(CountMeta.remaining, Count.n)
            .select(CountMeta.remaining, {0: "mark_done"}, default="parse_item"),
            # Accumulator loop: read one item, count down, exit at zero.
            "parse_item": extract(Item)
            .assign(CountMeta.remaining, CountMeta.remaining - 1)
            .select(CountMeta.remaining, {0: "mark_done"}, default="parse_item"),
            # No-extract pass-through state: constant metadata write, then stop.
            "mark_done": assign(CountMeta.done, 1).accept(),
        },
    )


if __name__ == "__main__":
    print(counted_items().to_json())
```
