## Parse graph

Start state: `parse_u0_ethernet`.

- **`parse_u0_ethernet`** — extracts u0_ethernet; selects on `u0_ethernet.ether_type`:
  - u0_ethernet.ether_type == 0x800 → `parse_u0_ipv4`
  - u0_ethernet.ether_type == 0x86dd → `parse_u0_ipv6`
  - u0_ethernet.ether_type == 0x876d → `parse_dash_hdr`
  - otherwise → **accept**
  > The source's `start` state (the eDSL reserves that name):
  > u0 EtherType demux, incl. the DASH packet-metadata sentinel
  > 0x876d; every miss accepts.
- **`parse_dash_hdr`** — extracts packet_meta; selects on `packet_meta.packet_subtype`:
  - packet_meta.packet_subtype == 0x1 → `parse_flow_key`
  - packet_meta.packet_subtype == 0x2 → `parse_flow_key`
  - packet_meta.packet_subtype == 0x3 → `parse_flow_key`
  - otherwise → `parse_customer_ethernet`
  > The wire packet_meta overwrites start's defaults; the
  > subtype demux routes FLOW_{CREATE,UPDATE,DELETE} through
  > flow_key (the source's first parser `if`), everything else
  > straight to the customer layer.
- **`parse_flow_key`** — extracts flow_key; selects on `packet_meta.packet_subtype`:
  - packet_meta.packet_subtype == 0x3 → `parse_flow_data`
  - otherwise → `parse_customer_ethernet`
  > CREATE/UPDATE stop at the key; DELETE carries flow_data
  > (the source's second parser `if`, re-keyed on the already-
  > extracted subtype).
- **`parse_flow_data`** — extracts flow_data; selects on `flow_data.actions`:
  - flow_data.actions == 0x0 → `parse_customer_ethernet`
  - flow_data.actions & 0x3 == 0x3 → `parse_flow_encap_u0_u1`
  - flow_data.actions & 0x3 == 0x1 → `parse_flow_encap_u0`
  - flow_data.actions & 0x3 == 0x2 → `parse_flow_encap_u1`
  - otherwise → `parse_flow_overlay_data`
  > The DELETE `if` cascade over flow_data.actions as one
  > first-match select: actions == 0 -> nothing extra; otherwise
  > flow_overlay_data always, plus the encap header per ENCAP_U0/
  > ENCAP_U1 bit (masked arms over the low two bits).
- **`parse_flow_overlay_data`** — extracts flow_overlay_data; then `parse_customer_ethernet`
  > actions != 0 with neither encap bit: overlay data only.
- **`parse_flow_encap_u0`** — extracts flow_overlay_data, flow_u0_encap_data; then `parse_customer_ethernet`
- **`parse_flow_encap_u1`** — extracts flow_overlay_data, flow_u1_encap_data; then `parse_customer_ethernet`
- **`parse_flow_encap_u0_u1`** — extracts flow_overlay_data, flow_u0_encap_data, flow_u1_encap_data; then `parse_customer_ethernet`
- **`parse_u0_ipv4`** — extracts u0_ipv4; selects on `u0_ipv4.version`:
  - u0_ipv4.version == 0x4 → `parse_u0_ipv4_ihl`
