- **`parse_ethernet`** — extracts ethernet; selects on `ethernet.ether_type`:
  - ethernet.ether_type == 0x8847 → `parse_mpls1`
  - ethernet.ether_type == 0x8848 → `parse_mpls1`
  - ethernet.ether_type == 0x800 → `parse_ipv4`
  - ethernet.ether_type == 0x86dd → `parse_ipv6`
  - otherwise → **accept**
- **`parse_mpls1`** — extracts mpls; selects on `mpls.bos`:
  - mpls.bos == 0x0 → `parse_mpls2`
  - mpls.bos == 0x1 → `parse_payload_nibble`
  - otherwise → **accept**
  > First of the two bounded MPLS labels (`max = 2` in the
  > source). The source's `map(bos, next-header)` peeks a 4-bit
  > pseudo-field from the NEXT header; transcribed by dispatching
  > on `bos` alone - bos=0 continues the stack with nothing else
  > consumed, bos=1 hands off to the nibble state.
- **`parse_mpls2`** — extracts mpls; selects on `mpls.bos`:
  - mpls.bos == 0x1 → `parse_payload_nibble`
  - otherwise → **accept**
  > Second MPLS label; a third (bos=0) falls to the default -
  > beyond the graph's bound is simply not a recognized
  > sequence.
- **`parse_payload_nibble`** — extracts mpls_payload_nibble; selects on `mpls_payload_nibble.v`:
  - mpls_payload_nibble.v == 0x0 → `parse_eompls_rest`
  - mpls_payload_nibble.v == 0x4 → `parse_ipv4_rest`
  - mpls_payload_nibble.v == 0x6 → `parse_ipv6_rest`
  - otherwise → **accept**
  > One shared state for both MPLS depths: extract the first
  > nibble of the payload, then continue with the matching
  > `*Rest` header (b10000/b10100/b10110 in the source's map).
- **`parse_ipv4`** — extracts ipv4; then **accept**
- **`parse_ipv4_rest`** — extracts ipv4_rest; then **accept**
- **`parse_ipv6`** — extracts ipv6; then **accept**
- **`parse_ipv6_rest`** — extracts ipv6_rest; then **accept**
- **`parse_eompls_rest`** — extracts eompls_rest; then `parse_ethernet2`
- **`parse_ethernet2`** — extracts ethernet2; then **accept**
  > The source's `ethernet2`: the inner (pseudo-wire) Ethernet
